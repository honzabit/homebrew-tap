# honzabit/tap

Homebrew formulae for [whoq](https://github.com/honzabit/whoq), an RDAP-first WHOIS for humans and agents.

```
brew trust honzabit/tap
brew install honzabit/tap/whoq
```

Homebrew 7 and later only load formulae from taps you have trusted, so `brew trust` is needed once per machine.

`Formula/whoq.rb` is updated automatically by whoq's release workflow; don't edit it by hand.
